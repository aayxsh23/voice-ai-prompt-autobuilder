# Skill: Save Context Before Compacting

**Instructions:**
1. Summarize the current task, recent decisions, and blockers.
2. Update the MEMORY.md file in the root directory. Do not overwrite the entire file; append the new context under a timestamped heading.
3. Instruct the user to run /compact.
